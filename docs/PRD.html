Product Overview Scholify is a mobile-first academic companion designed for university students. It consolidates attendance tracking, grade calculation, assignment management, and academic planning into a single intelligent app — eliminating the need for spreadsheets, sticky notes, and mental math. App Name Scholify Platform Android via React Native Primary Users University students (initially UPES, scalable to all universities) Core Problem Students struggle to track attendance, grades, and deadlines across multiple courses in one place Grading System Configurable per university — ships with UPES 10-pt scale (O=10, A+=9, A=8…) 2. Design Principles All screens designed in Stitch should adhere to the following guiding principles: • Clarity first — information hierarchy is paramount; the most critical stat (attendance %, current grade) is always the largest element on screen • One-tap interactions — marking attendance, logging marks, checking off assignments should each require no more than one tap • Predictive, not reactive — the app should tell students what will happen, not just what has happened • Configurable per course — every student has a unique timetable and grading scheme; the app never assumes a universal structure • Calm color system — green (safe), amber (warning), red (critical) for attendance and grade thresholds; avoid aggressive UI patterns 3. Feature Specifications 3.1 Smart Attendance Tracker The attendance module is the core feature of Klarr. It gives students a real-time view of their attendance across all courses and predicts future standing based on remaining classes. Sub-Feature Description Course Setup Students create courses manually or by uploading their timetable image (OCR-parsed). Existing courses can be initialized with current attendance data (e.g., 8/10 classes attended) for mid-semester onboarding. Live Attendance % Displays current attendance as a fraction and percentage per course (e.g., 8/10 — 80%). Color-coded: green ≥ 80%, amber 75–79%, red < 75%. One-Tap Marking After each class time (from timetable), the app prompts: Present / Absent / Late. One tap marks and saves. Classes Can Skip Calculates how many classes the student can miss and still maintain 75% minimum. Updates in real time after each mark. Future Projection Maps future classes using timetable + academic calendar (holidays auto-excluded). Shows projected attendance if student attends all remaining classes. Predictive Alerts Push notification before class: 'Skipping today drops you below 75% in Data Structures. You currently cannot afford to miss this class.' Holiday Sync Academic calendar with university holidays is integrated. Classes falling on holidays are automatically excluded from counts. 3.2 Assignment Manager A streamlined task manager built specifically for academic assignments — simpler than a general to-do app, smarter than a calendar. Sub-Feature Description Add Assignment User inputs: Assignment title, Course name, Due date, Priority (High / Medium / Low), optional notes or attachment link. Due Date Feed All pending assignments displayed sorted by due date (soonest first). Each card shows days remaining with urgency color coding: green (>5 days), amber (2–5 days), red (<2 days). Course Filter Filter/group assignments by course so students can focus on one subject at a time. Mark Complete Swipe right to complete. Completed assignments move to an archive, not deleted — students can review what was submitted. Overdue Detection Assignments past due date are flagged with an overdue badge and moved to a separate Overdue section. Reminder Notifications Smart reminders sent 3 days before, 1 day before, and on the morning of the due date. 3.3 Grade Calculator A fully configurable grade calculator that mirrors the student's actual examination scheme. As marks come in, the app continuously projects the current grade and what is needed in remaining assessments. Sub-Feature Description Scheme Setup Students configure the grading scheme per course: component names (IA, Mid Sem, End Sem), weightage percentages, and sub-components (Quiz 1 15%, Quiz 2 15%, Class Test 1 15%, Assignment 20%, etc.). Ships with UPES scheme as a default template. Mark Entry As results arrive, students enter marks for each component. The app validates against maximum marks defined in setup. Current Grade Continuously updated projected grade based on marks entered so far. Displayed prominently as both percentage and letter grade (O / A+ / A / B+ etc.). What-If Simulator Interactive sliders for pending components. Student adjusts 'What if I score 75 in End Sem?' and sees projected final grade update in real time. Grade Target Table A table showing minimum marks needed in each remaining component to achieve each grade band (O, A+, A, B+, B, C+, C). Updates dynamically. Grade Distribution Configurable grade scale per university. UPES 10-pt scale pre-loaded: O=10.0, A+=9.0, A=8.0, B+=7.0, B=6.0, C+=5.0, C=4.0, F=0. 3.4 CGPA Planner Helps students track their cumulative GPA across semesters and simulate how current semester performance will affect their overall standing. Sub-Feature Description Semester History Student enters CGPA and credits for previous semesters. Current Semester Auto-pulls projected grades from Grade Calculator module for all current courses. Credit Weighting Each course has an assigned credit value. CGPA calculated as weighted average across all semesters. Simulation Mode Adjust projected grades and see the resulting CGPA impact instantly. Target CGPA Set a target CGPA (e.g., 8.0) and the app back-calculates what grades are needed this semester. 3.5 Study Session Tracker A lightweight Pomodoro-style focus timer integrated with the student's courses and assignments. Sub-Feature Description Start Session Student selects a course or assignment, sets a focus duration (25 / 45 / 60 min), and starts the timer. Focus Mode Minimal full-screen UI during session. Option to block app notifications. Session Log Logs total study hours per course per week. Shown as a weekly bar chart on the dashboard. Study Streak Tracks consecutive days with at least one study session. Encourages consistency. 3.6 Exam Countdown Hub A dedicated section for upcoming assessments with countdown timers and quick-access study links. Sub-Feature Description Exam Entry Student adds exam name, course, date, time, and exam type (Quiz / Mid Sem / End Sem / Assignment). Countdown Cards Each exam shown as a card with a live countdown (X days Y hours). Ordered by proximity. Pin Priority Exams Pin up to 3 exams to the home dashboard for constant visibility. Calendar View Month view showing all exams and assignment due dates overlaid on academic calendar. 3.7 Notification Intelligence Context-aware push notifications that give students actionable, relevant nudges — not generic reminders. Sub-Feature Description Attendance Alerts Before class: 'You cannot afford to skip [Course] today.' After class time passes without marking: 'Did you attend [Course]? Tap to mark.' Grade Alerts After entering marks: 'You need 68+ in End Sem to achieve an A in [Course].' Assignment Alerts 3 days before, 1 day before, and morning of due date. Escalating urgency tone. Weekly Digest Sunday evening summary: courses at risk, upcoming week's exams, pending assignments. Smart Suppression Notifications suppressed during known exam periods and late at night (configurable quiet hours). 3.8 Course Health Score A composite score per course giving students an at-a-glance health indicator combining attendance, grades, and assignments. Sub-Feature Description Score Calculation Weighted composite: Attendance status (40%) + Current grade standing (40%) + Pending assignments (20%). Outputs a score from 0–100. Visual Indicator Displayed as a colored ring/arc on each course card: Green (75–100), Amber (50–74), Red (0–49). Home Dashboard All courses shown with their health rings on the main dashboard. Red courses float to the top. Drill Down Tapping a course card opens the detailed view showing all three components of the health score and quick-action buttons. 4. Navigation Structure Scholify uses a bottom tab bar as its primary navigation pattern — standard for React Native and familiar to mobile users. • Tab 1 — Home: Dashboard with health rings, today's schedule, pinned countdowns • Tab 2 — Attendance: Full attendance tracker with course list and detail views • Tab 3 — Grades: Grade calculator and CGPA planner • Tab 4 — Assignments: Assignment feed and add screen • Tab 5 — More: Exam countdown hub, study timer, settings A floating action button (FAB) on the Home, Attendance, and Assignment screens provides quick-add access to the most common actions: Add Assignment, Mark Attendance, Add Exam. 6. React Native — Technology Recommendations React Native is an excellent choice for Klarr. Here is a breakdown of recommendations and justification: 6.1 Why React Native is a Good Fit • Single codebase for iOS and Android — maximizes efficiency for a solo or small team build • Large ecosystem — libraries for everything needed: calendars, charts, notifications, OCR • Antigravity compatibility — React Native is well-supported by no-code/low-code wrappers • Strong community — vast documentation, Stack Overflow support, and active GitHub maintainers • Performance — near-native performance for UI-heavy apps like dashboards 6.2 Recommended Libraries Sub-Feature Description Navigation React Navigation v6 — Bottom tabs + Stack navigator. Industry standard. State Management Zustand — lightweight, simple API, perfect for academic data models. Avoid Redux overhead. Local Database WatermelonDB or SQLite (via expo-sqlite) — offline-first, fast queries for attendance/grade records. Charts & Graphs Victory Native or Recharts — for study hours bar chart, grade trend line, attendance arc. Calendar react-native-calendars — highly customizable, supports marked dates for exams and holidays. Push Notifications Expo Notifications — easiest setup for scheduled/local notifications (attendance alerts, reminders). OCR / Timetable Upload Google ML Kit (via react-native-mlkit) — for parsing timetable images. Animations React Native Reanimated 2 + Moti — smooth card transitions, progress rings, swipe gestures. Icons react-native-vector-icons (MaterialCommunityIcons) — comprehensive academic icon set. Forms react-hook-form — fast, performant form handling for assignment and grade entry screens. 6.3 Architecture Recommendation • Folder structure: /screens, /components, /stores (Zustand), /hooks, /utils, /constants • Offline-first: all data stored locally with WatermelonDB; no backend required for v1 • Expo managed workflow: fastest path to build + Antigravity integration • TypeScript: strongly recommended for a data-heavy app to avoid runtime errors 6.4 Potential Challenges • OCR accuracy for timetable parsing — test on handwritten vs printed timetables; have a manual fallback • Notification scheduling on iOS requires explicit user permission — handle gracefully in onboarding • WatermelonDB setup is non-trivial — allocate extra setup time vs AsyncStorage 7.
